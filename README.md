# GigRadar

GigRadar - приложение для поиска концертов и отслеживания любимых исполнителей

## Команды Telegram-бота

В личном чате с ботом доступны:

- `/start` — приветствие и ссылка на приложение
- `/help` — список команд
- `/concerts` — пять ближайших концертов за 30 дней
- `/concerts Мельница` — поиск по названию концерта или артиста
- `/subscriptions` — подписки из того же профиля, что и в приложении
- `/app` — открыть приложение, чтобы управлять подписками и настройками

## Локальный запуск бота

Укажите `TELEGRAM_BOT_TOKEN` в `.env` и запустите `docker compose up -d --build bot`. Compose также запустит PostgreSQL и API, чтобы подготовить схему базы данных. Для кнопки Mini App можно указать `TELEGRAM_APP_URL` с публичным HTTPS-адресом; без него команды поиска и подписок продолжают работать
