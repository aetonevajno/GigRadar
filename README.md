# GigRadar

GigRadar - приложение для поиска концертов и отслеживания любимых исполнителей

## Команды Telegram-бота

В личном чате с ботом доступны:

- `/start` — приветствие и ссылка на приложение
- `/help` — список команд
- `/concerts` — ближайшие концерты за 30 дней
- `/concerts Мельница` — поиск по названию концерта или артиста
- `/artists Мельница` — поиск артиста и подписка прямо в чате
- `/subscriptions` — список подписок
- `/favorites` — избранные концерты
- `/city Москва` или `/city all` — выбрать город или показать все города
- `/language ru` или `/language en` — выбрать язык сообщений бота и приложения
- `/app` — открыть приложение с полным каталогом и настройками

В карточке концерта можно добавить его в избранное, подписаться на артиста и открыть источник. Избранное и подписки общие с приложением. Для поиска концерта из любого чата через `@имя_бота запрос` включите inline-режим в BotFather (`/setinline`)

Язык можно изменить в разделе Настройки приложения или командой `/language` в боте. Выбор сохраняется в профиле и применяется также к уведомлениям. Поддерживаются русский и английский; новые профили используют русский язык.
Все переводы приложения, бота и уведомлений находятся в `locales/ru.json` и `locales/en.json`.

## Локальный запуск бота

Бот на aiogram находится в каталоге `bot/` и запускается отдельным контейнером. Укажите `TELEGRAM_BOT_TOKEN` в `.env` и запустите `docker compose up -d --build bot`. Compose также запустит PostgreSQL и API, чтобы подготовить схему базы данных. Для кнопки Mini App можно указать `TELEGRAM_APP_URL` с публичным HTTPS-адресом; без него команды поиска и подписок продолжают работать
